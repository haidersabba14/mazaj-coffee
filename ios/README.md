# تطبيق مزاج للإدارة — iPhone وiPad

تطبيق SwiftUI أصلي للإدارة فقط، دون WebView أو واجهة الموقع. أدخل كلمة مرور الإدارة فقط. يتصل بنفس API وقاعدة بيانات الطلبات، دون مفاتيح سرية مضمّنة. يظهر الطلب **بانتظار القبول**؛ اضغط قبول لتجهيزه أو رفض لإلغائه.

التنبيهات **داخل التطبيق أثناء فتحه فقط** مع تحديث لوحة الطلبات كل ٣٠ ثانية. لا توجد خدمة APNs أو إشعارات خلفية في هذه النسخة. عند انتقال iOS للخلفية لا نعد باستمرار التحديث. الموقع يبقى PWA بديلًا مجانيًا يعمل دون IPA.

## البناء من GitHub

يوجد Workflow يدوي باسم **Build iPhone IPA** في `.github/workflows/ios.yml`. الوضع الافتراضي يبني ملف IPA **غير موقّع** دون أسرار؛ يحتاج توقيعًا موثوقًا قبل تثبيته. خيار signed يبني للتوزيع على الأجهزة المسجلة عند تهيئة شهادات Apple. لم يُختبر على جهاز iPhone فعلي في هذه البيئة.

لإخراج IPA قابلة للتثبيت على أجهزة مسجّلة:

1. يلزم Apple Developer مع شهادة **Apple Distribution** بصيغة P12 ومفتاحها الخاص، وملف **Ad Hoc provisioning profile** يطابق Bundle ID ويضم UDID للأجهزة التي ستثبت التطبيق. العضوية عادة مدفوعة؛ لم نفعّلها أو نوافق على شرائها. دونها استخدم PWA مجانًا، أو Xcode على Mac للتثبيت الشخصي بحساب Apple مجاني ضمن قيوده، وليس هذا Workflow التوزيع.
2. في GitHub Settings → Secrets and variables → Actions أضف Variables: `APP_BUNDLE_ID` (مثل `com.yourname.mazajadmin`) و`APPLE_TEAM_ID`.
3. أضف Secrets: `APPLE_CERTIFICATE_P12_B64` (الشهادة P12 بترميز Base64)، و`APPLE_CERTIFICATE_PASSWORD`، و`APPLE_PROFILE_B64` (ملف mobileprovision بترميز Base64). أدخلها مباشرة في GitHub، ولا ترسلها في الدردشة ولا ترفعها كملفات إلى المستودع.
4. راجع حصة GitHub Actions المجانية لحسابك قبل التشغيل. macOS يستهلك حصة أكبر من Linux؛ Workflow يدوي ولا يبدأ على كل push. لا تفعّل تجاوزات مدفوعة.
5. Actions → Build iPhone IPA → Run workflow، وفعّل signed فقط عند توفير الشهادات. بعد نجاحه تُنزّل `MazajAdmin-IPA` من Artifacts خلال ٣ أيام. التوقيع Ad Hoc يعمل فقط على الأجهزة المدرجة في profile، وليس على كل أجهزة العالم. لا يتم النشر على App Store أو TestFlight تلقائيًا.
6. ثبّت على الجهاز المسجّل بأدوات Apple المناسبة مثل Apple Configurator أو Xcode، ثم أدخل كلمة مرور الإدارة. عنوان Worker محفوظ في إعداد التطبيق العامة؛ لا توجد صفحات موقع العملاء داخله.

## على Mac محلي

ثبّت Xcode وXcodeGen، ثم:

```sh
cd ios
export APP_BUNDLE_ID=com.yourname.mazajadmin
xcodegen generate
open MazajAdmin.xcodeproj
```

اختر فريقك والتوقيع المناسب داخل Xcode، وابنِ على جهازك. للتوزيع استخدم Product → Archive ثم Distribute App مع profile الصحيح. إصدار Xcode قد يحتاج تعديل نوع التصدير `release-testing` إذا تغيّرت تسمية خيارات Apple.

لا تُرفع الشهادة أو ملف provisioning أو IPA الموقّعة إلى ملفات Git. لا تتضمن النسخة رموز Apple/APNs. الاتصال محصور في HTTPS إلى نطاق المقهى المثبت في المصدر. كلمة المرور غير مضمّنة في ملف البناء.

النسخة غير الموقعة تبني التطبيق وتنتج ملف IPA فقط؛ ليست ملفًا صالحًا للتثبيت مباشرة. لم نستخدم أي خدمة توقيع خارجية. الرابط الافتراضي في التطبيق هو رابط Worker المنشور أعلاه.


الإدارة واجهة أصلية في التطبيق، وصفحاتها محذوفة من موقع الطلب. أُلغي رمز تفعيل الجهاز؛ تسجيل الدخول بكلمة المرور فقط، ويحمي API جلسة المسؤول. لا يوجد WKWebView أو موقع العملاء داخل التطبيق.
