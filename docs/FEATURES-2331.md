# سجل الميزات — الهدف 2331

2331 هدف تراكمي، وليس عدد ميزات الإصدار الحالي. لا نضيف ميزات مكررة لرفع العدد. «مختبر آليًا» يعني تحقق الاختبار المذكور، وليس اختبارًا على كل هاتف فعلي.

| النظام | الحالة | الدليل أو القيد |
|---|---|---|
