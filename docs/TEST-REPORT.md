# تقرير التحقق — Coffee Royal 3

اختبارات الإصدار تشمل Node + Miniflare مع D1 محلي فعلي؛ تُحاكى الشبكة الخارجية لـ Turnstile/Resend/Push، ولا يتم تعطيل التحقق الأمني في الإنتاج. لا تُنشأ طلبات زبائن وهمية على قاعدة الإنتاج أثناء QA.

مجموعة الخادم والواجهة: ٣٤ اختبارًا ناجحًا في الجولة النهائية، منها صلاحيات الموظفين، إلغاء الجلسات، رمز متابعة خاص، حالات الطلب، أرقام CR المتزامنة، عدم تكرار الاستدعاء، تأكيد الزبون، منع SSRF، المخزون المتزامن، الأرشفة والتصدير. نجح بناء الويب النهائي.

اختبارات Swift XCTest: انتقالات الحالات النهائية، فك إعدادات الخادم الافتراضية، وعدم تسمية قبول المزوّد «استلامًا». تُشغَّل على macOS Simulator في Workflow قبل إخراج IPA. لا يثبت نجاح Simulator تثبيت IPA غير الموقعة أو وصول APNs إلى هاتف.

حدود التحقق: إرسال البريد الحقيقي غير مختبر لغياب بيانات Resend. APNs والتوقيع وApple Wallet غير مختبرة لغياب حساب وشهادات Apple. تسليم Web Push وصوته على iPhone فعلي يحتاج تثبيت الموقع، الإذن، وجهازًا متصلًا؛ لا ندّعي أن مزودًا وافق يعني أن الجهاز استلمه.


## مراجعة متصفح حقيقي

Chromium على عرض 390×844 و1440×1000 ضد Worker/D1 محليين بنفس كود الإنتاج: ظهرت ١٢ بطاقة، لا تجاوز أفقي على الجوال، الحجم صغير/وسط فقط، سكر الشاي ثابت، شاشة انتظار ثم قبول ثم جاهزية، زر تأكيد التنبيه يكتب acknowledged_at فعليًا، واللغة تتحول إلى الإنجليزية. لم تظهر أخطاء JavaScript. صور المراجعة محفوظة في مساحة العمل الخاصة، ولا تتضمن بيانات إنتاج. الاختبار يعزل Turnstile والشبكات الخارجية؛ ليس اختبار تسليم Push فعلي إلى آيفون.


## بناء iOS الفعلي

[GitHub Actions run 43858159937](https://github.com/haidersabba14/mazaj-coffee/actions/runs/43858159937): نجحت اختبارات XCTest الثلاثة على iOS Simulator، ونجح بناء iphoneos Release دون توقيع. أُنشئ [Release 3.0.0 build 2](https://github.com/haidersabba14/mazaj-coffee/releases/tag/royal-manager-v3.0.0-2) مع IPA غير موقّع بحجم 492473 بايت، ومشروع Xcode الكامل وbuild-info.json. لا يلغي ذلك الحاجة لتوقيع IPA قبل التثبيت.


تحقق إرسال Web Push داخل workerd: قبل اختبار المزوّد المحاكى إشعارًا مشفرًا، وسُجل `sent` مرة واحدة رغم تكرار أمر الاستدعاء. صُحح استخدام redirect إلى `manual` بما يناسب Workers، ولا تتبع الخدمة تحويلات عناوين الاشتراكات. بقي acknowledged_at فارغًا حتى طلب تأكيد الزبون. هذا لا يدّعي اختبار التسليم على iPhone فعلي.

التحقق على النطاق المنشور: ١٢ منتجًا، لا زر اختيار عشوائي، صغير/وسط وسكر الشاي الثابت، API الإدارة ترجع 401 قبل الدخول وبعد الخروج، وD1 وTurnstile وWeb Push مهيأة. البريد وAPNs غير مهيأين كما تُظهر صفحة التشخيص. أعداد البيانات بعد الهجرة بقيت: طلبان وبطاقة ولاء واحدة؛ لم تُنشأ طلبات QA في الإنتاج.
