# تحسين دعم العربية والإنجليزية — الموقع 3.3.1

تم استكمال مسارات الزبائن في المتجر والحساب وبطاقة الولاء والفاتورة والجدولة والمساعد. لا تغيير لرابط الموقع أو مشروع Cloudflare أو قاعدة البيانات، ولا تغيير للأسعار أو الكميات أو صلاحيات الإدارة. يبقى تطبيق SwiftUI بإصدار 3.3.0؛ لا يحتاج هذا التحديث بناء IPA جديدًا.

## السلوك الفعلي

- اللغة المحفوظة تُطبق على الصفحات الأربع؛ النصوص والعناوين والحقول المساعدة ووسوم الوصول مترجمة.
- النصوص التي تصل بعد طلبات API تُترجم أيضًا. تحديث الحالة يبقى الأحدث عند تغيير اللغة، ولا يعود إلى نص قديم محفوظ.
- اختيار الموعد وحجم الكوب وإدخالات الاسم والهاتف والسيارة ومسودات الخلطة واللغز تبقى كما هي عند التبديل.
- أسماء العملاء والمجموعات والخلطات والملاحظات والرسائل الخاصة لا تُترجم تلقائيًا. أسماء الفروع والمحتوى المخصص من الإدارة تبقى بلغتها الأصلية إذا لم تتوفر لها ترجمة محددة.
- المواعيد تُنسق بالعربية أو الإنجليزية دائمًا بتوقيت البحرين، دون تغيير اللحظة المحفوظة أو أيام عمل الفرع.
- الحساب يعرض مستويات التجربة والشارات والنقاط والولاء وسجل النشاط والطلبات باللغتين، وتُعاد صياغة العدادات من بياناتها الحقيقية.
- الفاتورة تغيّر لغتها من البيانات المصرح بها الموجودة في الذاكرة، دون طلب الشبكة مجددًا. اسم العميل لا يتغير، ولا يظهر الهاتف أو رمز الوصول أو موقع البيت.
- مساعد قواعد المقهى يرجع الإجابتين في استدعاء واحد مع بقاء `reply` متوافقة مع العملاء السابقين. `lang` اختيارية، والافتراضي عربي. لا نموذج ذكاء اصطناعي خارجي ولا خدمة ترجمة مدفوعة.
- تبديل اللغة لا يفتح جلسة أو ينفذ طلبًا. مسح البيانات عند الخروج يلغي ارتباط عرضها بالترجمة؛ التبديل لا يعيدها. اكتمال نسخ رابط دعوة قديم بعد الخروج لا يُظهره للحساب التالي.
- إغلاق الفرع أو إيقاف الاستقبال يظهران بوضوح بجانب النموذج. الموعد الصالح يبقى قابلًا للتأكيد عند السماح بالحجز، مع بقاء فحص الخادم هو المرجع.

## التنفيذ

`public/i18n.js` يحتفظ بمصدر النص وآخر نسخة عرض، ويلاحظ تحديثات DOM المحددة. لا يكتب إلى قيم الحقول، ولا يبدّل أسماء أو مفاتيح الخيارات. تحديثات العرض لا تعيد تشغيل طلبات API، ولا تُنفذ نصوص HTML من معاملات الترجمة. `public/customer-locales.js` يحتوي قاموس المسارات الجديدة وقوالب العدادات والمواعيد.

الترجمات بشرية محددة في المشروع، وليست ترجمة عامة لمحتوى المستخدم. رسائل استثناء غير معروفة من النظام أو مزود خارجي قد تبقى بلغتها الأصلية. لا يُدّعى دعم ترجمة حرة لأي نص.

## الدليل

- **95 اختبارًا آليًا ناجحًا**: استمرت الاختبارات السابقة، وأضيفت اختبارات لغة محفوظة، محتوى يصل بعد التحميل، عدم إرجاع حالة قديمة، الحفاظ على المدخلات، عدم إعادة بيانات بعد الخروج، أمان HTML، عدم طلب الشبكة للتبديل، تخزين محلي محظور، وقت البحرين، ترجمة الصفحات الثابتة، مسودة اللغز، نسخ دعوة متأخر، وخصوصية المساعد بالإنجليزية.
- مراجعة Chromium باللغتين: طلب سيارة مجدول، حفظ الاختيار والحقول، قبول من الإدارة ثم تغيير اللغة، فاتورة خاصة، الخروج، حساب واسم عربي محفوظ، مسودة لغز وخلطة خاصة، بطاقة الولاء، وتبديل إجابات المساعد الموجودة. لم تُسجل أخطاء JavaScript، ولا تجاوز أفقي بعروض 320/390/768/1440.
- أُعيدت رحلة السلة والمفضلة والولاء عبر جهازين، خمس ختمات ومكافأة مشروبين، التعديل والإلغاء وإرجاع الرصيد، والفاتورة والخروج بين التبويبات؛ نجحت.
- الحالات التجريبية على D1 محلية فقط. لا إنشاء حساب أو طلب اختبار في قاعدة الإنتاج، ولا اختبار مدّعى لبريد أو Push فعلي.

يبقى إعداد البريد وAPNs وتوقيع IPA وApple Wallet كما هو موضح في دليل النشر. لا يفعّل هذا التحديث خدمة مدفوعة أو يحل محل الشهادات المطلوبة.
