# نشر Coffee Royal 3

## الموقع والبيانات

المشروع باقٍ في المستودع نفسه، وPages `mazaj-cafe` والنطاق https://mazaj-cafe-995.pages.dev وD1 `mazaj-coffee` كما هي. لا حاجة لتغيير DNS. لوحة الإدارة المنفصلة: `/manager.html`؛ لا يوجد رابط لها في متجر الزبائن. صفحتها shell عام دون بيانات، وكل القراءة والتعديل عبر API يتطلب جلسة. `/admin*` القديمة تظل 404.

قبل التحديث: أُخذ Git bundle وSQL export كامل في مجلد خاص خارج المستودع العام، مع tag `royal-before-rebuild-20261116`. لا ترفع SQL إلى GitHub. طبّق migrations بالترتيب `0004`, `0005`, `0006` بعد نسخة احتياطية؛ كلها إضافات، ولا تحذف الطلبات أو بطاقات الولاء. أرقام CR جديدة فريدة مع بقاء UUID ورمز المتابعة القديم صالحين. الساعات يوميًا من ١٥:٠٠ بتوقيت البحرين، وجميع المشروبات مجانية، عنصر واحد لكل طلب ومشروبان للمكافأة.

الاستعادة الكاملة: استعمل Cloudflare D1 Time Travel أو import SQL بعد معاينة النسخة ونطاق البيانات المراد استعادته. أمر الاستعادة قد يستبدل بيانات حديثة، لذلك لا ينفذه التطبيق تلقائيًا. نسخة JSON التشغيلية من اللوحة خاصة بالمالك، تشمل جداول العمل ولا تشمل الجلسات أو أسرار Apple/VAPID/Resend. حد التصدير ١٠٠٠٠ صف لكل جدول؛ ليست بديلًا عن SQL export كامل. لا يوجد زر استعادة JSON مباشر في هذه النسخة.

## Web Push

مكتبة `@block65/webcrypto-web-push` تستخدم Web Crypto وaes128gcm وVAPID المتوافق مع Apple. أنشئ زوج P-256 مرة واحدة: المفتاح العام بصيغة uncompressed raw (65 bytes) بترميز base64url، والخاص هو قيمة `d` من JWK. عيّن على Pages وWorker المجدول:

- `VAPID_PUBLIC_KEY`: مفتاح عام.
- `VAPID_PRIVATE_KEY`: Cloudflare Secret، لا يُرسل للمتصفح ولا Git.
- `VAPID_SUBJECT`: رابط الموقع العام.

احفظ الزوج ولا تغيّره دون خطة لإعادة اشتراك الأجهزة. التشغيل لا يحتاج خدمة Push مدفوعة أو عضوية Apple للمقهى. على iPhone/iPad يلزم iOS/iPadOS 16.4 أو أحدث، وإضافة الموقع إلى الشاشة الرئيسية ثم فتحه منها والضغط على تفعيل الإشعارات. لا يمكن للموقع تثبيت نفسه بصمت على الآيفون. زر التثبيت يشرح Safari → مشاركة → إضافة إلى الشاشة الرئيسية. Android يستعمل beforeinstallprompt حين يتوفر.

الإرسال مرتبط بـ UUID الطلب ورمز خاص محفوظ مجزأ على الخادم؛ لا يتيح رقم CR وحده الاشتراك أو المتابعة أو التأكيد. ٣ أجهزة لكل طلب كحد أقصى. عناوين Push محصورة في مزودي Apple/FCM/Mozilla عبر HTTPS دون redirects. لا تُقبل روابط داخلية. الإشعار لا يتضمن اسم العميل أو هاتفه أو عنوانه أو رمز المتابعة.

زر جاهز يستدعي الزبون افتراضيًا، وزر نادِ الزبون يعيد نفس العملية بدون تكرار. الاستدعاء واحد لكل طلب في هذه النسخة. طابور D1 يحجز lease، بحد ٤ محاولات مع تأخير متزايد، ولا يعيد الإرسال إلى اشتراك قبله المزوّد سابقًا. تُعطَّل الاشتراكات المنتهية 404/410. يعالج Worker المجدول المحاولات كل ١٠ دقائق، وتسرّع اللوحة المفتوحة المحاولة المستحقة أثناء تحققها الدوري. لا تعتمد Pages على cron خاص بها.

حالات الخدمة:

- `pending/retry/sending`: انتظار أو معالجة.
- `sent`: قبل المزوّد الطلب، وليس دليلًا على التسليم.
- `no_subscription`: لا يوجد جهاز مشترك.
- `unconfigured`: ينقص إعداد الخدمة.
- `failed/expired`: فشل أو انتهى الاشتراك.
- `acknowledged_at`: ضغط الزبون «استلمت التنبيه»، وهو التأكيد الوحيد الصريح من الزبون.

الصوت المتكرر يعمل داخل صفحة الطلب المفتوحة بعد الضغط لتفعيل الصوت، ويتوقف عند الإقرار أو الكتم أو إغلاق الصفحة. لا يمكن تشغيل صوت ويب متكرر في الخلفية أو تجاوز صامت/تركيز iOS. إشعار الخلفية يستخدم صوت النظام بحسب إعدادات الجهاز، ولا يرن جهاز مطفأ بالكامل. لا يُدّعى تسليم Push إلى iPhone فعلي دون اختباره على جهاز مثبت ومشترك.

## إدارة وصلاحيات

المالك `owner` مع كلمة المرور الحالية، والموظفون حسابات PBKDF2 مستقلة. كلمة المرور ليست في المصدر. الجلسة HttpOnly Secure SameSite Strict مدتها ٨ ساعات. عمليات POST تتحقق من Origin، والقراءة لا تتيح CORS. كل API إدارية تتطلب الجلسة، والموظف ممنوع من الحسابات والتقارير والنسخ والسجل وإعدادات التشغيل. تعطيل الحساب أو تعديل صلاحياته يلغي جلساته. الأجهزة الأصلية مرتبطة بالجلسة لإيقاف إرسال الطلبات إلى جلسة ملغاة.

تغييرات الحالات تفحص الانتقال والإصدار لمنع موظفين من الكتابة فوق حالة أحدث. تحديث المخزون وسعة الطلبات يتحقق ذريًا في D1 triggers. الإلغاء يعيد مخزون المشروب مرة واحدة. لا يمكن إعادة فتح طلب ملغي أو مسلّم. سجل العمليات لا ينسخ ملاحظات العملاء أو كلمات المرور.

## البريد والتكلفة

Resend يحتاج `RESEND_API_KEY` Secret و`EMAIL_FROM` من نطاق موثق. المستلم محفوظ في الخادم. لم تُضَف بيانات إرسال فعلية، فلا ندّعي وصول بريد. فشل البريد لا يلغي الطلب. APNs أصلي مُجهز في المصدر لكنه يحتاج توقيع Apple ومفاتيح كما في `ios-manager/README.md`.

لا خدمات مدفوعة فُعّلت. تبقى حصص Cloudflare/GitHub/مزود البريد مرتبطة بخطتك. تحقق من لوحة الحصص الحالية قبل توسيع الفروع أو polling؛ هذه النسخة تستخدم تحققًا كل ٥ ثوانٍ للإدارة وكل ١٠ ثوانٍ للعميل أثناء الفتح، ولا تُعد بزمن لحظي ثابت. CSV يفتح في Excel، وليس ملف XLSX أصليًا. لا يوجد WebSocket/Durable Objects في هذه النسخة.
