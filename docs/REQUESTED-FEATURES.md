# مطابقة قائمة الوظائف المطلوبة

لا تُعد العبارات المتكررة وظائف مستقلة للوصول إلى 2331. هذه مطابقة قائمة المالك الأصلية ذات 110 بنود، مع القيود التي غيرها لاحقًا. «منفذ» يعني وجود وظيفة حقيقية؛ دليل الاختبارات الفعلي وحدوده في TEST-REPORT. التكامل الخارجي ليس تسليمًا مثبتًا إلى جهاز فعلي.
