# Coffee Royal — Obsidian & Copper

واجهة جديدة بالكامل على نفس مشروع `mazaj-cafe` ونطاقه: خلفية سوداء، نحاسي، صور كبيرة، قائمة بعمودين للجوال وأربعة للكمبيوتر، سلة ونوافذ متابعة وحساب عميل بتصميم متناسق. الوضع النهاري المحفوظ يبقى خيارًا، والافتراضي للعملاء الجدد أسود.

الموقع يستعمل نظام الطلبات الحالي، وليس قاعدة تجريبية. بقيت الفروع والمخزون والمكونات والإدارة الأصلية وتطبيق SwiftUI والولاء والخصوصية والتتبع وPWA. لا روابط للإدارة في واجهة الزبون. لم تُستبدل شهادات أو أسرار، ولم تتغير معرّفات Cloudflare.

## إضافات قابلة للاستخدام

- اضغط صورة مشروب لعرض وصفه وصورته واختيار صغير أو وسط. «إضافة للسلة» و«اطلب الآن» يستخدمان السلة الحقيقية وحدود الخادم.
- مشاركة رابط `/?drink=tea#menu` تفتح معاينة المشروب إذا كان متاحًا. QR القائمة يحتوي رابط الموقع العام فقط ويمكن حفظه SVG للطباعة.
- تفضيلات الحجم والسكر والقوة والحرارة والحليب تُحفظ محليًا دون اسم أو هاتف أو عنوان. الشاي والقهوة العربية دائمًا سكر عادي، حتى بعد إعادة فتح السلة أو إعادة الطلب.
- التقييم متاح من صفحة الطلب بعد التسليم. يثبت العميل الملكية بجلسة الحساب أو رمز الطلب الخاص. يمكن تعديل التقييم دون مضاعفة عدد المراجعات. لا أسماء ولا تعليقات عامة؛ تُعرض النجوم والعدد والمتوسط الفعلي فقط. نافذة الاحتفاظ بالتقييمات مرتبطة بالطلب (30 يومًا).
- البحث والمفضلة والشراء المباشر وإعادة الطلب والسلة والمكافآت تظل تعمل. لا اختيار عشوائي أو عروض بأرقام مزيفة.

## السلامة والتراجع

قبل التعديل أُخذت نسخة SQL كاملة وGit bundle في مسار خاص خارج المستودع؛ لا تُنشر بيانات العملاء. الوسم `royal-before-copper-20261116` يحتفظ بكافة الملفات السابقة. الهجرة `0009_verified_ratings.sql` إضافية فقط. لتراجع الواجهة يُعاد نشر إصدار الوسم دون إسقاط جداول أو استعادة قاعدة قديمة فوق طلبات جديدة.

كل الملفات القديمة موجودة في سجل Git؛ لم يُحذف أي ملف من المشروع في هذا الإصدار. ملفات CSS أُعيدت كتابتها بموافقة تغيير التصميم، ومعرّفات النماذج الأساسية ووظائفها مستمرة.

راجع `FEATURES-2331.md` لحالة الميزات، و`TEST-REPORT.md` للأدلة. لا يعني هذا الإصدار اكتمال 2331 ميزة. البريد يحتاج إعداد Resend، وIPA القابل للتثبيت وAPNs وWallet المباشر تحتاج توقيع وشهادات Apple كما هو موثق؛ لم تُفعّل خدمة مدفوعة.
