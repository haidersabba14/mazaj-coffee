# Coffee Royal 3.3 — تشغيل متقدم

هذه توسعة حقيقية للنظام الحالي، وليست ادعاء إنجاز 2331 ميزة. تبقى جميع المشروبات مجانية، مشروب واحد في الطلب العادي ومشروبان عند استبدال رصيد المكافأة. لا تعديل للرابط أو هوية مشروع Cloudflare، ولا حذف لطلبات أو حسابات أو بطاقات موجودة.

## ما أُضيف

- طلبات مجدولة بربع الساعة، حتى ٧ أيام، وسعة موعد تُحجز ذريًا في D1. يبدأ التحضير فقط عند وقته. المكونات تُحجز منذ تأكيد الطلب، ولا يُعاد حجزها في وقت الموعد.
- ساعات عمل أسبوعية لكل فرع تتقاطع مع ساعات التشغيل العامة. استقبال فوري بعد ٣ عصرًا؛ يمكن حجز موعد لاحق متاح قبل فتح المقهى.
- استلام من السيارة مع وصفها وزر «وصلت للمقهى»، وسجل زمني خاص بالطلب.
- فترات توفر للمشروبات الموسمية، عنوان الموسم، إبراز مشروب، وتعديل زمن التحضير.
- مركز تحديثات خاص بالحساب وتعليم المقروء دون مسح تنبيهات وصلت بعد القراءة.
- توصيات من التفضيلات والمفضلة، ومساعد إرشادي بقواعد محلية. لا ادعاء استخدام نموذج ذكاء اصطناعي مدفوع أو توليد نص خارجي.
- طقس البحرين الفعلي من MET Norway مع تخزين مؤقت واحترام المصدر؛ لا تُرسل إحداثيات بيت العميل لخدمة الطقس. يتوقف الاقتراح بوضوح إذا تعذر الحصول على بيانات صالحة.
- مجموعة طلبات برابط دعوة؛ كل عضو يسجل ويؤكد طلبًا مستقلاً، دون مشاركة أسماء أو هواتف أو تفاصيل طلبات الأعضاء. الحد الشخصي لا يتغير.
- خلطات خاصة مسماة من المشروبات والتخصيصات المسموحة، مع إعادة الطلب.
- نقاط تجربة، أكواب موثقة، مستويات Bronze/Silver/Gold/VIP، شارات، تتابع زيارات، ولغز يومي بمحاولة واحدة. هذه مزايا معنوية وليست ختمات أو استحقاقات مالية؛ لا تضيف رصيد مشروبات تلقائيًا.
- بطاقات هدايا أحادية الاستخدام تمنح رصيد مشروبين؛ الكود يظهر مرة ويُحفظ مجزأً فقط، وصلاحيتها ١–٩٠ يومًا. يمكن إلغاء غير المستبدلة.
- هدية ميلاد اختيارية يعتمدها المالك يدويًا ضمن ٧ أيام من اليوم والشهر، مرة في السنة، مع بطاقة مرتبطة. لا نجمع سنة الميلاد.
- مصادقة TOTP اختيارية للمالك والموظف، سر مشفر، رموز استرداد أحادية الاستخدام، ومنع إعادة استخدام الرمز. لا تتغير طريقة الدخول حتى تفعيلها وتأكيدها من صاحب الحساب.
- معاينة واستعادة تشغيلية آمنة بدمج المنتجات والإعدادات والفروع والمكونات والوصفات فقط. تأكيد مكتوب، صلاحية خمس دقائق، منع التعارض، ومنع التطبيق أثناء وجود طلبات نشطة. لا ترفع بيانات العملاء أو كلمات المرور ولا تحذفها. ليست بديلاً عن استعادة SQL الكاملة عبر Cloudflare.
- تقارير دورية يومية/أسبوعية/شهرية عن الفترة المكتملة، بعد ٨ صباحًا البحرين خلال دورة cron التالية، حتى ٣ جداول لكل مالك، وحفظ ٩٠ يومًا، وتنزيل Excel/JSON دون بيانات الاتصال.
- شاشات SwiftUI أصلية للمواعيد والمواسم والهدايا والحماية والاستعادة والتقارير، وتسجيل دخول برمز TOTP عند تفعيله.

## التحقق

نجحت ٧٩ حالة اختبار آلية على D1 محلية فعلية، تشمل التزامن والخصوصية والتفويض وسعة المواعيد والهدايا والاستعادة والمصادقة والتقارير. نجح البناء الإنتاجي. توثق مراجعة المتصفح وبناء Xcode ونتائج النشر في TEST-REPORT بعد اكتمالها؛ لا تعني الاختبارات المحلية وصول بريد أو Push إلى جهاز فعلي.

## النشر دون فقد بيانات

أُخذت نسخة SQL خاصة كاملة ونسخة Git قبل التغيير. تُطبق migrations 0011–0018 بالترتيب على قاعدة البيانات نفسها، ثم يُحدث Worker للـcron وPages للواجهة. لا تغيّر الأسرار الموجودة، خصوصًا CUSTOMER_AUTH_SECRET؛ يُستخدم أيضًا لحماية بذور TOTP. لا تفعّل خدمة مدفوعة.

## قيود خارجية لم تتغير

الإرسال إلى iCloud يحتاج إعداد Resend وعنوان مرسل مسموحًا وتجربة حقيقية. APNs وIPA قابل للتثبيت يحتاجان توقيع Apple المناسب؛ Wallet الأصلي يحتاج شهادة Pass Type ID. بطاقة QR تعمل دونها. لا يستطيع موقع إجبار هاتف مطفأ على الرنين أو تجاوز الصامت/التركيز. Web Push يتطلب دعم النظام، تثبيت PWA على iPhone عند اللزوم، والإذن. قبول مزود الإشعار يختلف عن تأكيد الزبون.
