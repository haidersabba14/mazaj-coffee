# Coffee Royal 3.1 — ميزات التشغيل والتخصيص

هذه دفعة فعلية من تطوير المنصة، وليست ادعاء إكمال 2331 ميزة. يحافظ الإصدار على الرابط والبيانات والمجانية والحجمين صغير/وسط، وعلى حذف الاختيار العشوائي.

## الإضافات

- اسم دخول مالك قابل للتهيئة عبر `ADMIN_USERNAME`، مع PBKDF2 لكلمة المرور. عند تهيئته لا يقبل الاسم القديم أو كلمة المرور وحدها. بيانات المالك الفعلية محفوظة في Cloudflare ولا تُضاف إلى Git أو IPA.
- رفع صور JPEG/PNG/WebP من اللوحة، وتصغيرها إلى WebP، ورفع صور من استديو iOS مع إزالة بيانات الصورة الأصلية بإعادة الرسم. مكتبة صور وحذف غير المستخدمة فقط. حد 200 KiB لكل صورة، 100 صورة؛ مخزنة في D1 دون تفعيل R2 مدفوع. الروابط صور منتجات عامة ولا تحتوي بيانات زبائن. الإضافة تدعم نمط تشغيل صغير؛ إذا توسعت المكتبة فاستعمل R2 بعد تقييم الكلفة.
- مخزون للمكونات بوحدات غرام/مل/قطعة، بدقة 0.001 وحدة، وحد إعادة طلب، وإيقاف المكوّن.
- وصفة لكل مشروب. خصم ذري لكل مكونات الطلب. حفظ الاستهلاك الأصلي للطلب وإرجاعه مرة واحدة عند الإلغاء، حتى إذا تغيرت الوصفة لاحقًا. إخفاء المشروب من القائمة عند نقص مكوناته. تظل القهوة كاملة الدسم والمقاسات الحالية كما هي.
- تنبيهات نقص مخزون المكونات والأكواب. لا تدعي هذه النسخة إرسال إنذار خارجي مستقل للمخزون.
- تقارير بفترة زمنية وفرع بتوقيت البحرين: إجمالي الطلبات والملغاة، متوسط الانتظار والتحضير، أداء الفريق، المشروبات، وتوزيع الطلبات على ساعات اليوم والفروع.
- ملف Excel XLSX حقيقي مع العربية واتجاه RTL، مع CSV. لا يتحول النص إلى صيغة Excel قابلة للتنفيذ. حد 10000 صف للتصدير. بيانات الطلبات القديمة تخضع لسياسة الاحتفاظ 30 يومًا الحالية.
- شاشة أرشيف واستعادة ظهور الطلب مع الحفاظ على حالته المنتهية؛ لا تعيد فتح أو تجهيز الطلب.
- إضافة/تعديل/إيقاف الفروع من لوحة الويب والتطبيق الأصلي، مع ساعات مستقلة. الفرع يحتاج الساعات العامة مفتوحة أيضًا.
- محرر إدارة للون التمييز والخلفية والخط والأيقونات والثيمات وترتيب الأقسام والإحصائيات وإجراءات الطلب. أصوات ملكي/جرس/واضح، الكتم والاهتزاز ومستوى صوت التطبيق المفتوح. تحفظ لكل مستخدم وتُزامن عند فتح الجلسة أو تحديث التخصيص. إعدادات صوت APNs تبقى تحت تحكم iOS.
- شاشة تقارير فعلية داخل التطبيق مع مشاركة XLSX. شاشة مكونات ووصفات وأرشيف وفروع في التطبيق.

## التحقق والقيود

الاختبارات تستخدم D1 محليًا فعليًا وتختبر التزامن، الصلاحيات، الصور ببايتاتها، XLSX ومحتوى XML، قواعد التخصيص، وتغيير الدخول. فُتح XLSX الناتج أيضًا باستخدام openpyxl. اختبار المحاكي وبناء IPA في GitHub Actions مطلوبان قبل وصف الإصدار الأصلي بأنه جاهز.

لا توجد عضوية Apple أو شهادة Wallet أو بيانات Resend؛ الخدمات المرتبطة بها تبقى بحاجة إعداد. لا تظهر واجهة دفع أو مميزات عشوائية، ولا تدّعي المنصة اكتمال 2331 ميزة. متطلبات المستخدم المتعارضة السابقة يُقدّم عليها آخر قرار واضح: جميع المشروبات مجانية، واحد لكل طلب ومشروبان للمكافأة، والحليب كامل الدسم فقط.
